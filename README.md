# Java Day 42 - Library Management System

## About
A Java console application for managing library books, searching records, and issuing or returning copies.

## Features
- Add books with unique IDs
- View all books
- Search by book ID
- Issue available copies
- Return books
- Save book records in CSV format
- Load records when the program starts
- Validate user input

## Files
- `Main.java` - Main application and Book class
- `books.csv` - Sample book records

## How to Run
Compile:

`javac Main.java`

Run:

`java Main`

Keep `books.csv` in the program's working directory.

## Concepts
Object-oriented programming, classes, encapsulation, ArrayList, CSV file handling, exception handling, and menu-driven applications.

## Important Note
This is an educational library system. It tracks available copy counts, not individual borrowers or issue dates.
